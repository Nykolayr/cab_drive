# Smoke-лист после релиза (5 минут)

Прогонять на устройстве после каждого релиза в стор/TestFlight.
Провалы — не «на глаз», а по критерию в каждом пункте.

1) Где: вход → главная.
   Шаги: войти под тест-номером `+7 111 xxx-xx-xx` (код `2259`).
   Ожидание: вход без зависаний, главная открылась.
   Провал: краш, вечный спиннер, повторный запрос кода.

2) Где: «Заказы» → «Активные» (водитель).
   Шаги: создать тест-заказ заказчиком → отклик водителя → назначить.
   Ожидание: заказ виден в «Активные» у водителя.
   Провал: заказ создан и назначен, но вкладка пустая.

3) Где: страница заказа водителя.
   Шаги: пройти статусы до конца («завершил») → клиент подтверждает.
   Ожидание: заказ уходит в «Архив» у обоих, статус «Доставлен».
   Провал: заказ исчез из всех вкладок или завис в «Активные».

4) Где: заказ → «⋮» → «Отменить заказ» (клиент).
   Шаги: а) на newOrder/spec_set — отменить; б) после «водитель завершил» — пункт должен отсутствовать.
   Ожидание: а) заказ в архиве у обоих с «Заказ отменен»; б) пункта нет, если есть — сервер отвечает «Водитель уже завершил заказ…».
   Провал: отмена прошла после завершения водителем / заказ исчез бесследно.

5) Где: пуши.
   Шаги: сменить цену заказа (клиент или админка) → ждать пуш у водителя.
   Ожидание: баннер при открытом и при свёрнутом приложении; на сервере крошки `apns_ok`/`fcm_token_ok`/`register=` у iOS.
   Провал: пуш не пришёл за 1-2 мин; у iOS `apns_timeout_20s`.

6) Где: серверные логи (по желанию): `journalctl -u cab.service` — без новых traceback на пройденные шаги.
