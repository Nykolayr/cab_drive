# Формат QA-чеков

Любой чек / «проверь» / «ок?» для пользователя или заказчика — **только** в формате ниже. Без абстракций.

## Запрещено

- «Проверь аватар в профиле», «логин ок», «рейтинг», «онборд», «созданные игры».
- «Должно работать», «посмотри там», «в настройках».
- Слова без маршрута: «модуль», «флоу», «квиз», «force-reboot» без шагов.

## Обязательный формат каждого пункта

```
N. Где: <экран / таб / кнопка по подписи в UI>
   Шаги: 1) … 2) … 3) …
   Ожидание: <что увидеть / чего не должно быть>
   Провал: <что считать багом>
```

## Правила

1. **Подписи как на экране** — «Мои события», «Скрепка», не `my-games` / `ImagePicker`.
2. **Один результат** — либо ок, либо нет; не «может появиться».
3. **Сначала сам открой UI в коде** (экран, кнопка, роут) — потом пиши чек. Нет кнопки «Перенос рейтинга» → не пиши её.
4. После фикса — **тот же** чек, не новый размытый.

## Пример

❌ `10. Аватар в профиле`

✅
```
10. Где: таб «Профиль» → карандаш / «Редактировать» → блок фото сверху
    Шаги: 1) Тап по аватару или «Изменить фото» 2) Выбрать картинку из галереи 3) Сохранить профиль 4) Назад на «Профиль»
    Ожидание: на табе «Профиль» сразу то же фото (не плейсхолдер); без системного отказа «нет доступа к фото» из-за лишнего permission
    Провал: фото не сменилось / краш / снова старое после выхода
```
